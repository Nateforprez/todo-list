TODO LIST (Task Management Web App) 

DESCRIPTION
----------- 
A full stacak task management web application that supports user account creation and manage daily workflows. Similar to a Todo list, users are able to add up 
to 30 tasks with unique attributes of there choosing, filter by urgency, and check off tasks. 

FEATURES
-------
- User Authentication (User account creation and task storage)
- Task Management: Add up to 30 tasks. 
- Task Attributes: Customize your tasks with their own names, descriptions, and urgency levels. 
- Interactive UI: User-friendly GUI and seamlessly cross out tasks in real time. 
- Smart Filtering: Quickly sort and filter out tasks by task attributes. 


TECH STACK
------------

FRONTEND 
---------
- React 
- TypeScript 

BACKEND 
-------
- Express.js
- Node.js
- MongoDB
